# 2026-08-31 全量公司跨产业板块核查

- 核查范围：133 家现有去重公司，不新增公司。
- 核查结果：43 家具有经专项验证的补充业务，共新增 69 条候选映射。
- 映射变化：135 → 204；多板块公司：2 → 44；原有公司、映射和评级不覆盖。
- 首页不保留“本次新增”筛选或新增角标；多板块公司会在对应产业板块分别出现。

## 核查口径

1. 逐家检索巨潮公司主营简介，并结合现有业务描述及上一轮50家公司收录依据筛查。
2. 对拟追加的跨板块业务，以公司年报、半年报、公告或官网产品文件作专项验证。
3. 简介可能滞后；未追加不意味着公司绝无其他业务，也不代表已逐份审计133家公司最新全部定期报告。
4. 仅产品/服务直接相关或已并表子公司业务入库；客户用途、少数股权投资、在研规划、退出并表业务不据此入库。
5. 云服务和算力运营确有交集，允许双映射；设备子行业及集团/子公司重合在风险中说明，统计不把映射数当公司数。
